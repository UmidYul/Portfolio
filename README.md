# Визитка — Умид Йулдашев

Одностраничная визитка: контакты, короткая информация о себе, две темы и три языка.
Статика, без сервера и без зависимостей в рантайме.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | вся страница: разметка, тексты всех трёх языков, логика |
| `src.css` | исходные стили: токены тем, стекло, переворот, анимации |
| `qr.js` | генератор QR-кода, без зависимостей |
| `styles.css` | собранный Tailwind — **этот файл грузит браузер**, править его вручную не нужно |
| `tailwind.config.js` | палитра акцентов и шрифты |
| `avatar.jpg` | фото, квадратное, кадрируется по кругу |
| `favicon.svg` | иконка вкладки |
| `vercel.json` | статический хостинг и заголовки кеша |

## Разработка

```bash
npm install
npm run dev     # пересобирает styles.css при каждом изменении
```

Открывать `index.html` можно прямо двойным щелчком — сервер не нужен.

Перед коммитом собери минифицированную версию:

```bash
npm run build
```

`styles.css` коммитится в репозиторий намеренно: на Vercel ничего не собирается,
файлы отдаются как есть. Поэтому если поменял классы в `index.html` и забыл
`npm run build` — на сайте стилей не будет.

## Как поменять

**Акцентный цвет.** В `src.css` в блоках `.theme-dark` и `.theme-light` поменяй
`--accent` и `--accent-ink`. Четыре готовых варианта перечислены там же в шапке:
латунь (по умолчанию), терракот, оливковый, индиго. В тёмной теме берётся светлый
оттенок, в светлой — тёмный, иначе проседает контраст текста на кнопке.

**Фото.** Замени `avatar.jpg` файлом с тем же именем. Квадратное, от 400×400.

**Тексты и языки.** Все три языка лежат в объекте `DICT` в конце `index.html`.
Элементы с атрибутом `data-i18n="ключ"` подставляют значение по этому ключу.
Чтобы добавить новую строку: вешаешь `data-i18n="мойКлюч"` на элемент и добавляешь
`мойКлюч` во все три словаря.

**Контакты.** Ссылки в разметке, в блоке `id="p-c"`. Там же обнови `vcard`
в скрипте, иначе кнопка «Сохранить контакт» отдаст старые данные.

## Деплой

```bash
git push
```

Дальше на Vercel: New Project → импортировать репозиторий → Framework Preset
оставить `Other` → Deploy. Сборка не нужна, `vercel.json` это уже указывает.

После привязки домена поправь в `index.html` путь в `og:image` на абсолютный —
иначе превью ссылки в Telegram и WhatsApp останется без картинки.

## Что внутри

- Одна карточка: контакты, «О себе» и действия внутри неё, без нижней панели
- Переворот на QR-код по кнопке в правом верхнем углу
- Две темы, запоминаются в `localStorage`, при первом заходе берётся системная
- Три языка с мгновенным переключением, без перезагрузки
- Живое время Ферганы (`Asia/Tashkent`)
- Кнопка «Сохранить контакт» — отдаёт `.vcf`, телефон добавляет в контакты
- «Поделиться» — системное меню на телефоне, копирование ссылки на компьютере
- Всё движение отключается при `prefers-reduced-motion`

## QR-код

`qr.js` — собственная реализация кодировщика: байтовый режим, уровень коррекции M,
версии 1–6 (до 106 символов). Библиотек нет намеренно, иначе ради одной функции
пришлось бы тянуть зависимость в статическую страницу.

Код строится из текущего адреса страницы в момент первого открытия обратной стороны.
Если страницу открыли файлом с диска (`file://`), адреса нет — тогда берётся
`FALLBACK_URL` в начале скрипта в `index.html`. **После привязки домена поставь туда
свой адрес**, иначе при локальном открытии QR будет вести не туда.

Генератор проверен двумя способами: матрицы сверены с эталонной библиотекой `qrcode`
(совпадают побитово при одинаковой маске), и каждый сгенерированный код прочитан
декодером `jsQR` — 113 случаев, включая кириллицу и длины от 1 до 106 символов.

Фон кода прозрачный: сквозь него видно то же стекло, что и у карточки. Модули берут
цвет текста (`--qr-ink`) и перерисовываются при смене темы. Контраст 13:1 в тёмной
теме и 16:1 в светлой. Тихая зона — 4 модуля.

**Важно про полярность.** В тёмной теме получается инверсия: светлые модули на тёмном
фоне вместо классических тёмных на светлом. Камера айфона и Google Lens такое читают,
но часть встроенных сканеров в приложениях принимает только классическую полярность.
Проверено декодером: с поддержкой инверсии читается, без неё — нет. В светлой теме
полярность обычная, поэтому там код берут любые сканеры — это и есть запасной вариант,
если какой-то сканер заупрямится.

Вернуть классический вид — две правки: в `renderQR` добавить обратно подложку
`<rect fill="...">`, а `--qr-ink` в тёмной теме поменять на цвет фона.

## Стекло

`.glass` — четыре слоя, а не одна полупрозрачная плашка:

1. `.glass` — матовость (`backdrop-filter`), подкраска, внутренние кромки;
2. `::before` — градиентная кромка в пиксель через `mask-composite`, торец стекла;
3. `::after` — статичный блик у верхней кромки;
4. `.ab` — хроматическая аберрация по краю, еле заметная.

Все цвета выведены из палитры: менять стекло отдельно от темы не нужно.

**Про преломление.** Слой `feDisplacementMap` через `backdrop-filter` был сделан и
удалён по результатам замера в браузере. На безопасной амплитуде (`scale 6`) карточка
с преломлением и без него выглядят одинаково, а на заметной (`scale 10` и выше) в
правом нижнем углу появляется светлый клин. Причина в самом макете: за карточкой почти
ровный фон с мягкими световыми пятнами — преломлять нечего. Плюс `url()` внутри
`backdrop-filter` исполняет только Chromium. Если под карточку когда-нибудь ляжет
фотография или узор, эффект имеет смысл вернуть.

Внутренние поверхности (`.surf`) намеренно **без** `backdrop-filter`: карточка уже
размывает фон, вложенное размытие даёт грязь, а вместе с `transform` на наведении оно
ещё и ломает композитинг в Chrome.

Если браузер не умеет `backdrop-filter` вовсе, `@supports` подменяет заливку на
непрозрачную.


## Движение

Единая система, а не анимации поверх готового макета:

- **Появление** — ступенчато, через переменную `--d` на каждом элементе и общий
  `@keyframes rise`. Класс снимается по `animationend`, иначе `animation-fill-mode:
  both` навсегда зафиксировал бы `transform: none` и убил все `:hover`.
- **Вкладки и язык** — общий компонент `.pill`: бегунок едет к активной кнопке, по нему
  пробегает световой блик (`.sweep`). Геометрию держит **только CSS** (`--i` задаёт
  номер активной кнопки), замеров в скрипте нет. Раньше бегунок позиционировался через
  `offsetLeft`, но у него не были заданы `left`/`top` — абсолютный элемент вставал в
  статическую позицию внутри флекс-контейнера, и трансформация добавлялась сверху,
  сдвигая его на лишние 4 пикселя.
- **Высота карточки** — `.panels` с переходом по `height`; значение ставит JS, а
  `ResizeObserver` пересчитывает его при смене языка.
- **Строки контактов** — не пять одинаковых плашек, а один материал с волосками между
  строками и подсветкой `.links-hl`, которая едет за курсором и за фокусом.
- **Тема** — цвета переключаются волной: фон сразу, стекло через 70 мс, текст через 140.
- **Курсор** — свой, кольцо с точкой: обычный и увеличенный акцентный над кликабельным.
  Собран как `data:`-SVG в переменных `--cur` и `--cur-act`, по одной паре на тему,
  с тёмным или светлым ореолом, чтобы кольцо было видно и на стекле, и на кнопке.
  На тач-экранах отключается — там курсора нет.
- **Прокрутка** — фон уезжает с параллаксом, а на тач-экранах, где курсора нет, свет по
  стеклу ведёт именно прокрутка. Появление при прокрутке срабатывает один раз
  (`IntersectionObserver` + `unobserve`), поэтому назад ничего не переигрывается.
- Фон останавливается, когда вкладка уходит с экрана.
- Всё перечисленное выключается при `prefers-reduced-motion`.

## Переворот

Лицевая сторона лежит в потоке и задаёт высоту, обратная растянута по ней через
`inset: 0`. Поэтому высота при перевороте не меняется ни на пиксель и скачков быть не
может — без всякого JS. Анимация: `perspective` на контейнере, `rotateY(180deg)` на
внутреннем слое, `backface-visibility: hidden` на обеих сторонах, 620 мс.
